# MATLAB maths scripts

Sixteen MATLAB scripts using the symbolic toolbox and plotting: functions and inverses, quadratic roots, derivatives, RL and RLC circuit voltages, an LC circuit solved as a differential equation, resonant frequency, area between curves, complex numbers, linear systems and a Fourier series with my own coefficient function. Language: MATLAB.
