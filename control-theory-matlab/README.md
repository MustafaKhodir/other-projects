# Control theory MATLAB scripts

Four scripts covering classical control: converting a transfer function to state space, a pole zero map, a step response with and without an extra pole, and the root locus of a three phase synchronous machine with its controller so the stabilising gain can be read off. They need MATLAB with the Control System Toolbox. Language: MATLAB.
